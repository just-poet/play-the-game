# Play the Game

A 3D browser adventure through a forest, a beach, a café, a courtyard house, and a lantern-lit lake.

Download **Play the Game.html** from the [latest release](https://github.com/just-poet/play-the-game/releases/latest) and open it in a browser. The game and soundtrack are included in the HTML, so it works offline. Click **Let's play** to start the game and sound.

## Controls

- **Left / Right** to change lanes and **Space** to jump during a run.
- **WASD** or the **arrow keys** to explore.
- **Esc** to pause. Touch controls appear on narrow screens.

## Build from source

Run these commands from the repository root.

```sh
cd Source
npm ci
npm run build
```

The build writes **Play the Game.html** to the repository root.
